# Logos

The mark is an **asymmetric pair**: an outlined circle (the operator's assertion), a tinted circle (the consumer's acceptance) and their overlap, solid (authority). It's built on a 64 grid: two circles of radius 18, centres 16 apart, with the lens between them.

| File | Use |
| --- | --- |
| `authoritative-software-mark.svg` | Primary mark on light grounds: an `accent` outline, an `accent-soft` disc and an `accent` lens |
| `authoritative-software-mark-dark.svg` | On dark grounds: the `accent` and `accent-soft` dark values |
| `authoritative-software-app-icon.svg` | App and touch icons at 32 px and above: the mark in `on-accent` and `accent-soft-on-accent` on an `accent` tile with `radius-mark` corners |
| `favicon.svg` | Browser tab, 16–32 px: the same icon with a heavier outline (4.5 rather than 3) so the operator circle survives at small sizes |
| `social-card.png` | The 1200×630 Open Graph card. It still shows the previous mark and needs re-rendering |
| `previous-two-circles.svg` | The retired two-outline mark, kept for reference only |

**Lockup:** the mark at the cap height plus ascenders of the name, 12px gap, then "Authoritative Software" on one line in `serif` 400 at -0.02em tracking. There's no wordmark file: set the name in type.

**Clear space:** at least the lens width (20 units) on every side.

**Don't:** make the circles symmetric, swap which one is outlined, fill the whole shape in one colour, put text inside the mark, or use any colours other than the accent family.
